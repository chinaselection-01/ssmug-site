SSMug 签到终端 · 硬件 BOM 采购简报

场景：咖啡店/景区放一台固定 NFC 读取终端，顾客拿 Social Bottle 碰一下即打卡，大屏显示今日榜，店家后台看谁来过。
定位：卖给店家/景区的「定制硬件 + 部署」一次性包，不养服务器（后端走 Cloudflare Workers，月费≈0）。

推荐方案 A — 安卓平板 + USB NFC（最快落地）

最容易翻车的 3 个点（DFM / 运维）

1. 供电与 WiFi 稳定性：终端要 7×24 在线。断网=无法写后端、榜不更新。给店家配稳定 WiFi 或 4G 路由兜底。
2. 读卡器位置：顾客是"拿杯碰终端"，杯子里的 NFC 贴片若在金属杯底会被屏蔽（同 v2 杯的 RF 净空坑）。终端读取区要明显标识"放这里"，并测试不同杯型的读取距离。
3. 店家不会维护：做成"插电即用、远端更新页面"，故障率集中在屏碎/读卡器掉线。备 1 台周转机比教店家修更省事。

落地步骤（MVP）

  1. 先软件后硬件：用 terminal.html + admin.html（mock 数据）去谈 1–2 家咖啡店，确认有兴趣。
  2. 接真后端：部署 Cloudflare Workers（见 workers/README.md），把 terminal.html / admin.html 的 API 改成 workers.dev 域名。
  3. 打样 1–2 台终端：按方案 A 买平板+ACR122U+定制外壳，送店实测读卡距离与 WiFi。
  4. 铺杯：前提是顾客有 Social Bottle（带 NFC 贴片 + 已登记资料），否则终端无用武之地。
  5. 上线运营：店家后台看"谁来过/今日榜"，你按台收硬件+部署费，后端不养。

商业口径（给店家的话术）

"我们提供一台带您店 logo 的签到终端 + 会员社交杯。顾客拿杯碰一下就打卡上榜，您后台能看到谁来过、攒积分、解锁隐藏菜单——不用装 App，不用掏手机。一次买断硬件+部署，数据走我们的轻量云，没有月租。"
